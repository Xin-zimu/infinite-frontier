# V4.0.0 known issues

- Base names use the configured automatic sequence and cannot yet be renamed in the UI.
- A world supports at most three bases; this is an intentional persistence and presentation bound.
- Base boundaries are summarized in the home panel and are not drawn as a permanent world overlay.
- Home travel targets the exact beacon tile and does not expose a user-selected arrival offset.
- Home travel is intentionally unavailable inside procedural dungeons.
- The cooldown advances only with saved in-game time; closing the game adds no wall-clock progress.
- Asset totals are derived across the complete mutable state and refresh after contributing system events; they are not a continuously animated per-frame counter.
- V4.1 ocean and island expansion and later roadmap systems are intentionally excluded.
