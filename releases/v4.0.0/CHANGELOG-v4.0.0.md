# Infinite Frontier V4.0.0

## Complete survival-building loop

- Added the craftable homestead beacon and a validated three-base management contract.
- Added 24-tile base ranges, 32-tile minimum beacon spacing and stable base names.
- Combined shelter, storage, farming, husbandry, cooking/potions, smelting, equipment enhancement and automation into one eight-step base loop.
- Added live counts for buildings, stored items, crops, mature harvests, tamed animals, products and machines.
- Added active-home selection and safe return travel from the surface or underground.
- Added a 120-second successful-travel cooldown and explicit dungeon restriction.
- Added the responsive `X`-key homestead panel and dedicated building category.
- Advanced save format to 25 with logical home metadata cross-validated against chunk-owned beacon placements.
- Retained generation format 5 and its canonical checksum.
