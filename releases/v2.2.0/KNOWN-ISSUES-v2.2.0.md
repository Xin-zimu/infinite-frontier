# V2.2.0 known issues

- Gift preferences are role-wide rather than individually generated personality traits.
- Village reputation currently affects local merchant prices; faction-wide reputation arrives in V2.4.
- Relationship rewards are item grants rather than bespoke NPC quest chains; the quest framework arrives in V2.3.
- Stock lists remain fixed and do not yet react to events or seasons.
- NPC current walking position remains session state and is reconstructed from the active schedule.
