# V3.2.0 changelog

- Added nine data-driven player blueprints across ground, structure and roof placement layers.
- Added live placement preview, six-tile range, quarter-turn rotation and explicit terrain/resource/overlay/support validation.
- Added atomic material deduction and demolition refunds, including capacity rollback and non-empty-chest protection.
- Added batched shared-atlas rendering, physical walls/furniture, and door collision that follows open state.
- Added persistent eight-slot storage with durable-item metadata and normal `E` interaction.
- Connected placed workbench/campfire stations to crafting and player torches/campfires to lighting and survival heat.
- Advanced save format to 19 with chunk-owned player-building records, stale-file cleanup and format-2-through-18 migration.
- Preserved generation format 5 and its canonical terrain checksum.
