# V2.1.0 known issues

- NPC schedules use village service points and cardinal paths; advanced obstacle avoidance and indoor maps remain future polish.
- Shop stock is an intentionally fixed data-driven list in this version and does not yet react to reputation, factions or dynamic events.
- NPC identity and interaction history persist, but current walking position is session state and is reconstructed from the active schedule.
- Sleeping is currently available through village innkeepers only; player-built beds belong to the later building system.
- NPC visuals are readable procedural placeholders pending the unified art/animation pass.
