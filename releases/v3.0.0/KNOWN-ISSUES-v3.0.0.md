# V3.0.0 known issues

- Random contracts use four rule families and existing objective types; later content packs may add more authored wording and targets.
- A board refreshes at the next in-game day for each region. Real-world time while the game is closed never refreshes it.
- World choices currently communicate consequences through text, faction standing and progress rather than bespoke cinematic scenes.
- Escort objectives use canonical NPC-role meetings; free-moving companion AI is outside this milestone.
- The journal intentionally presents one choice at a time to keep all controls inside the minimum viewport.
