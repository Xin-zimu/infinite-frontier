# V2.0.0 known issues

- Generation format 5 intentionally changes generation-version-derived terrain/resource identities. Migrated V1.7 worlds retain coordinate-keyed permanent differences, but their unmodified generated surroundings follow V2.0 rules.
- Fast travel is limited to explicit discovered surface travel points; caves and active dungeons must be exited normally.
- The map is a chunk-scale exploration view rather than a zoomable tile-level cartography editor.
- Custom markers use the default name and color in this version; naming/color editing belongs to later UI polish.
- Regional Bosses reuse the common enemy behavior and validation art. Unique production animations/audio remain scheduled for the unified content pass.
