# V2.0.0 changelog

- Expanded the deterministic biome catalog from nine to twelve entries with taiga, savanna and meadow.
- Added wild-boar and frost-sprite normal enemies and strict role filtering for ordinary populations.
- Added three seed-deterministic surface regional Bosses with biome preferences, separate discovery rings and stable sigil rewards.
- Added persistent 3×3 fog reveal, automatic landmark discovery, completion markers and up to 32 custom markers.
- Added a responsive full-screen world map, `M` input, travel-point list and safe surface fast travel.
- Advanced save format to 10 for exploration and regional-Boss state; added explicit format-9/generation-4 migration.
- Advanced generation format to 5 for the twelve-biome world and recorded the new canonical checksum.
- Rebuilt the offline CJK subset from current runtime strings and added V2 glyph coverage to the release gate.
