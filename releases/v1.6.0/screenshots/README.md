# V1.6.0 screenshot evidence

`cave-preview.png` is generated locally by `tools/render_cave_map.gd` from a fixed seed.

- Dark cells: solid cave walls.
- Gray cells: connected walkable floor.
- Orange/gold cells: torches and treasure chests.
- Copper/gray/black accents: deterministic mineral veins.
- Gold grid lines: 32×32 underground chunk boundaries.
