# V1.6.0 known issues

- Cave entrances use a deterministic regional frequency and do not yet appear on an exploration map; map markers belong to the V2.0 exploration milestone.
- Cave walls use programmatic validation art. The unified production art/audio pass remains scheduled for V4.11.
- Static torches are generated landmarks rather than player-placeable objects; player construction begins in V3.2.
- Underground contains one cave layer in this version. Deep caves, lava, crystal caves and underground cities are scheduled for V4.3.
- Room-based dungeons, locks, traps, elite encounters and dungeon Boss state are intentionally deferred to V1.7.
