# V3.1.0 known issues

- Survival uses concise HUD bars and text rather than character-body animations for each status effect.
- Heat detection currently recognizes canonical nearby campfire/torch sources; the V3.2 placement system will expand player-built heat-source interaction.
- Food use targets the selected hotbar slot only and does not yet offer an inventory context menu.
- Poison exposure is available to gameplay systems and persistence, while broader poisonous plants/creatures arrive with later content passes.
- Turning survival off pauses existing attributes and effects; it intentionally does not erase them.
