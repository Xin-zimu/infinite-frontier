# V3.1.0 changelog

- Added bounded hunger, body temperature and wetness as continuously simulated survival attributes.
- Added biome, weather, phase, layer, water, heat and activity inputs to the environment composition.
- Added data-driven poison, burning, frostbite and starvation effects with duration, tick damage and movement modifiers.
- Added atomic `G`-key berry consumption with hunger, health, temperature and poison-recovery results.
- Added a responsive survival HUD and a settings toggle that pauses the complete rule set without erasing saved condition.
- Added death and inn recovery policies that clear temporary effects and restore safe attributes.
- Advanced save format to 18 with explicit neutral migration from formats 2–17.
- Preserved generation format 5 and the canonical V2.0 terrain checksum.
