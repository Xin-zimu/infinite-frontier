# V3.3.0 known issues

- Farming is limited to dry, clear surface tiles within six tiles of the player; underground and dungeon plots are rejected explicitly.
- Watering is a contextual action without a separate watering-can tool or water-container resource in this version.
- Crop simulation advances by in-game day and current canonical weather; it deliberately does not add wall-clock offline growth.
- V3.3 provides four crops, one fertilizer and one-cell plots. Seasonal calendars, soil exhaustion and multi-cell orchards remain future balancing/presentation work.
- Crop visuals use the project's generated shared pixel atlas; authored crop sprites and farming animations remain future presentation work.
- Animal husbandry, processing chains, equipment and automation are intentionally outside V3.3 scope.
