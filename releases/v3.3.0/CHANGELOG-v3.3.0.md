# V3.3.0 changelog

- Added four data-driven crops with staged growth, annual and regrowing harvest behavior, and ordinary/silver/gold outputs.
- Added contextual till, sow, water, fertilize and harvest actions through a responsive `H`-key farming panel.
- Added weather-aware day simulation: rain waters plots while snow and sandstorms apply explicit growth multipliers.
- Added deterministic care/fertilizer harvest quality plus fruit-tree and tomato regrowth.
- Added five farming-input recipes and seventeen canonical seed, fertilizer, sapling and harvest items.
- Added a batched farming chunk layer and reciprocal building/farming occupancy validation.
- Advanced save format to 20 with chunk-owned farm records, stale-file cleanup and format-2-through-19 migration.
- Preserved generation format 5 and its canonical terrain checksum.
