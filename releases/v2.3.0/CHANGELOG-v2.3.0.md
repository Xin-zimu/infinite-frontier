# V2.3.0 changelog

- Added ten validated fixed quests: six prerequisite-linked main quests and four retryable side quests.
- Added collect, defeat, explore and escort/meeting objective types using canonical content IDs.
- Added active limits, tracking, completion, reward claim, failure, abandonment and retry states.
- Connected inventory, exploration, enemy-death and NPC-talk runtime sources to quest progress.
- Added an `L`-key journal and compact always-on tracked-objective HUD.
- Added transactional reward delivery with full inventory rollback on capacity failure.
- Advanced save format to 13 and added explicit format-12 migration.
- Preserved generation format 5 and the V2.0 canonical terrain checksum.
