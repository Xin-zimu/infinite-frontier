# V2.3.0 known issues

- This version ships fixed authored templates; deterministic random quest generation arrives in V3.0.
- Escort objectives use stable NPC-role meeting checkpoints rather than a follower AI formation.
- Quest rewards are items only; faction standing rewards arrive with the faction system.
- The journal does not yet sort by distance because objective locations can refer to derived landmark types.
- Active quests have no wall-clock expiry; event-timed contracts arrive with dynamic world events.
