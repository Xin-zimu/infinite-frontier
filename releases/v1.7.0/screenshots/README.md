# V1.7.0 screenshot evidence

`dungeon-preview.png` is generated locally by `tools/render_dungeon_map.gd` from a fixed seed and stable entrance ID.

- Purple-black cells: solid dungeon walls.
- Gray cells: connected room and corridor floor.
- Blue: surface return exit.
- Rose: locked doors; yellow: keys; red: traps; orange: chests.
- Pink: elite encounters; violet: final dungeon Boss.
