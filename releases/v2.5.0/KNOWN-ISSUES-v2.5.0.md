# V2.5.0 known issues

- Event encounters reuse the current pixel enemy and environment presentation; bespoke caravan, meteor and rescue artwork is scheduled for the unified art pass.
- An event anchors to the player's chunk when it activates and does not relocate while active.
- Only one event is active at once in V2.5, keeping effects and objective ownership unambiguous.
- Future timetable entries show type and time but intentionally defer their activation chunk until the event starts.
- The timetable advances with game time only; no real-world offline progression occurs.
