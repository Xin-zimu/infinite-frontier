# V2.5.0 changelog

- Added eight validated dynamic world-event definitions covering every V2.5 roadmap event.
- Added a seed-deterministic schedule, current-region activation, objective progress and bounded outcome history.
- Added exact enemy-population, resource-yield and blizzard-weather effects that compose with existing weather modifiers.
- Connected trade, combat, harvest, exploration, Boss and NPC actions to matching event objectives.
- Added three event-qualified ash raiders for village attacks and one event-qualified temporary Boss.
- Added a `V`-key tracker and responsive active/upcoming/history timetable window.
- Advanced save format to 15 and added explicit format-14 migration with strict numeric normalization.
- Preserved generation format 5 and the V2.0 canonical terrain checksum.
